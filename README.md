
# Счётчик калорий

Небольшое веб‑приложение без сборки и зависимостей: автопоиск по встроенной базе продуктов и расчёт КБЖУ на указанное количество граммов.

## Возможности

- Автоподсказки по встроенной базе (`foodDB`) при вводе названия продукта
- Добавление продукта с указанием граммов
- Подсчёт итогов: продукты / ккал / белки / жиры / углеводы
- Удаление позиций и очистка списка
- Сохранение данных в **localStorage** (список сохраняется автоматически)

## Как запустить

Вариант 1: просто открой `index.html` двойным кликом.

Вариант 2 (рекомендуется): запусти любой статический сервер, например:

```bash
npx serve
```

## Структура проекта

```
.
├─ index.html
├─ css/
│  └─ styles.css
└─ js/
   └─ app.js
```

## Где править базу продуктов

Открой `js/app.js` и отредактируй объект `foodDB`. Значения указаны **на 100 г**:

- `cal` — ккал
- `p` — белки
- `f` — жиры
- `c` — углеводы
